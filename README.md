# Планировщик задач 
Простой планировщик задач. Позволяет хранить список задач, редактировать и удалять задачи, так же есть возможность задать правила повторения задачи. 

 # Список выполненных заданий со звёздочкой.
1. Реализована возможность задавать порт работы приложения через переменную окружения TODO_PORT
2. Реализована возможность указать путь к файлу базы данных через переменную окружения TODO_DBFILE
3. Реалзиованы правила повторения задач для недель и месяцев 
4. Реализован поиск задач по дате и части строки в заголовке и комментарии
5. Реализована аутентификация 
6. Реализован запуск приложения через docker и docker compose

# Запуску кода локально 
Приложение расчитано на работу с версией GO 1.26.x
Если будетет использовать другие версию нужно поправать файл go.mode. 

Склонирйуте репозиторий к себе и выполните комманду 
```bash
go run main.go 
``` 
После запуска приложения приложение будет доступно по адресу:
```bash
http://localhost:7540/
```
Для изменения параметров запуска приложения можно использовать переменные среды 

Вы можете настроить приложение через переменные окружения:

- **TODO_DBFILE** - путь к файлу базы данных (по умолчанию: `scheduler.db`)
- **TODO_PORT** - порт для запуска веб-сервера (по умолчанию: `7540`)
- **TODO_PASSWORD** - пароль для доступа к планировщику задач. Если значение не установлено, проверка пароле не производится.

**Пример запуска с указанием параметров:**
```bash
TODO_DBFILE=./data/tasks.db TODO_PORT=7540 TODO_PASSWORD=pass go run main.go
```


# Запуск приложения через Docker 
**Для запуска через docker compose**
Нахоясь в корневом каталоге проекта(где расположены docker файлы) выполните команду 
```bash
docker compose up -d --build 
```

**Для запуска через docker** 

Сборка образа:
```bash
docker build -t scheduler:latest .
```

Запуск контейнера (порт 7540, пароль 1234567!):
```bash
docker run -d --name scheduler -p 7540:7540 -e TODO_PORT=7540 -e TODO_DBFILE=/data/scheduler.db -e TODO_PASSWORD="1234567!" -v scheduler-data:/data scheduler:latest
``` 

После запуска приложения через docker или docker compose по умолчанию приложение будет доступно по адресу:
```bash
http://localhost:7540/
```
**Пароль**, прописанный в Docker файле,  **1234567!**
